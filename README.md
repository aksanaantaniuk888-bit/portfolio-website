
# Portfolio Website

## About the Project

This is my personal portfolio website created as part of the Techtonica program. It showcases my coding skills, work experience, and contact information.

The website is built using HTML and CSS and includes a responsive layout for different screen sizes.
## Technologies Used

- HTML
- CSS
- Git
- GitHub
- VS Code


## How to Run the Project

1. Clone or download the repository from GitHub.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. View the website in your browser.
